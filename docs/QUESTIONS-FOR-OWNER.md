# 제작자에게 묻는 질문

01-기획.md와 02-AI-활용-과정.md에서 제작자만 답할 수 있는 자리를 `[확인 필요: 질문 N]`으로 비워 두었습니다. 보고서·로그·Git에는 답이 없는 것들입니다. 답을 주시면 그 자리를 답으로 바꿉니다. 답이 없으면 각 질문 아래의 기본 문장을 넣겠습니다. 한두 줄이면 충분합니다.

- 지금 아는 것: 11-06 17:26에 Codex 브레인스토밍 세션이 열렸지만 이 앱과 연결되는지는 확인하지 못했습니다.
- 쓰이는 곳: 01-기획.md '문제'
- 답이 없으면: "이 문제를 처음 인식한 계기는 기록으로 남기지 않았습니다. 문제 설명은 실제 공고 1건과 시험용 공고에서 확인한 내용입니다."

- 쓰이는 곳: 02-AI-활용-과정.md '역할 분담', '비용과 운영 선택'
